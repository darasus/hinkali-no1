# Хинкали №1 — сайт

Одностраничный сайт хинкальной «Хинкали №1» в Сертолово (ул. Заречная, д. 8, рядом с «Пятёрочкой»).

Статический HTML без сборки: весь сайт в `index.html`.

## Локально

Откройте `index.html` в браузере или запустите:

```bash
npx serve .
```

## Обновить цены или часы

Отредактируйте соответствующие блоки в `index.html` (секции `#menu` и `#info`) и запушьте в `main` — Vercel задеплоит автоматически.
